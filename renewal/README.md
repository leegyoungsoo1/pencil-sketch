# 롱폼 뉴스/정보 영상

사진 이야기 작업실은 롱폼(가로 1920×1080)을 기본으로, 숏폼(세로 1080×1920)을 선택할 수 있습니다. 최대 60장면이며 롱폼 최대 10분, 숏폼 최대 3분입니다. 형식 선택이 대본의 실제 길이를 자동으로 늘리지는 않습니다. 중앙 자막은 롱폼 88px·숏폼 72px 기준, 두 줄 단위로 나누어 표시하고 어두운 반투명 배경을 사용합니다. 3분 초과 MP4는 지원 브라우저에서 임시 디스크로 내보내 메모리 부담을 줄입니다. 모바일 처리 속도와 지원은 기기에 따라 다릅니다. 긴 영상 회귀검증: `node renewal/test-browser.cjs --story --ui-only --long`.

# 이야기 보관함 관리 — 최근 20개

새 작품은 `assets/story/<slug>/`에 이미지·대본·project.json을 저장한 뒤 `python renewal/manage-library.py --add <slug>`로 등록합니다. 이 명령은 library.json의 맨 앞에 작품을 추가하고 스물한 번째 이후에 등록된 작품 폴더를 실제 삭제합니다. 반드시 목록과 삭제된 파일까지 함께 커밋·배포합니다. 등록되지 않은 폴더는 삭제하지 않습니다. 현재 등록 작품은 library.json을 기준으로 확인합니다.

모바일/PC는 같은 library.json을 읽습니다. 브라우저 숨기기가 아니라 게시된 파일 정리 방식입니다. 사용자가 다운로드한 MP4/재료 묶음과 Git 과거 커밋은 삭제하지 않습니다. 단순히 파일을 복사하는 것만으로는 등록되지 않으며 새 작품 제작 시 위 명령을 실행해야 합니다. 별도 서버·비밀번호는 없습니다.

검증: `python renewal/test-library.py` (스물한 번째 등록 시 가장 오래된 폴더 삭제, 스무 개 유지, 등록되지 않은 폴더 보존, 잘못된 경로 거부).

# 사진 이야기 작업실

`story.html`은 기존 스케치와 분리된 자막 중심 포토툰 제작 화면입니다. 사진과 문단별 대본으로 장면을 만들며 사진 배정·순서·대사·화자·시간·반전 전 뜸을 수정할 수 있습니다. 세로/가로 1080p 무음 MP4, SRT 및 이미지가 포함된 JSON 재료 묶음을 저장합니다. TTS는 사용자가 외부 편집에서 추가합니다. 자동 음성/이미지 생성 API는 연결하지 않았습니다.

첫 예제: `assets/story/mom-concert/`의 가상 엄마·딸 창작 상황극 4장, 24초. 내장 이미지 생성 도구로 제작했고 생성 명세와 대본은 같은 폴더의 PROMPTS.md, SCRIPT.md에 있습니다. 화면의 예제 불러오기 버튼으로 전체 재료를 불러옵니다.

사진 최대 12장(장당 15MB), 장면 최대 12개(장당 160자, 2–30초), MP4 최대 3분. 최신 Chrome/Edge의 WebCodecs가 필요하고 MP4 muxer는 기존 작업실과 같은 jsDelivr 버전을 사용합니다. 생성은 로컬 브라우저에서 수행되며 사진은 서버로 전송하지 않습니다. 새로고침 전에 재료 묶음을 저장해야 합니다.

검증: `node renewal/test-browser.cjs --story` — 24초 1080×1920 MP4, SRT 지연 타이밍, 재료 왕복, 잘못된 묶음, 가로/세로 프레임, 모바일 폭, 사진 삭제, 대본 분할, 저장 취소.

마법 효과에 붓의 곡선 이동과 붓끝의 짧은 빛 꼬리를 추가했습니다. 마지막 완성 장면과 PNG에는 붓을 표시하지 않습니다.

영상 길이 연동: 마법 완성은 사진별 영상 길이의 90% 동안 진행하고 마지막 10%는 완성본을 유지합니다. 만들기 직후에는 2.6초 요약 효과를 보여주며 실제 미리보기·저장은 설정한 전체 길이를 사용합니다.

# 추억 한 자루 — 공개 작업실

사진을 올리고 제목·편지를 더해 연필 드로잉 영상과 PNG를 만드는 독립 웹앱입니다. 원본 프로그램은 저장소 루트에 그대로 보존합니다.

- `index.html`: 소개 사이트
- `atelier.html`, `atelier-app.js`, `atelier.css`: 현재 작업실
- `upgraded.html`, `classic.html`: 현재 작업실로 이동하는 이전 주소
- `assets/site/`: 화실 소개 이미지, `assets/backgrounds/`: 선택 가능한 배경

사진 추가는 분석 없이 목록만 준비합니다. 삭제·정렬과 영상 방향 선택 후 **만들기**를 누릅니다. 제목·제목 글꼴·서명은 전체 공통, 손글씨 편지만 사진별로 저장합니다. 서명은 기본 공백·비활성이며 체크박스로 켭니다. 추천 문구는 제거했습니다.

희망 길이는 기본 20초/장, 10초 단위로 조정합니다. 아틀리에 연필화는 최소 2분이며, 그보다 긴 희망 길이를 선택하면 느리게 그립니다. 만들기 후 사진 목록 아래에 실제 합계가 표시됩니다. 선 진하기·해칭은 10% 단위입니다. 원본 전체 구도는 종이를 원본 비율에 맞춰 배치하며 편지와 서명도 종이 안에 들어갑니다. PNG는 각 사진을 별도 파일로 저장하고 브라우저의 다중 다운로드 제한 시 개별 링크를 제공합니다.

반복 작업 시 렌더링 컨텍스트와 잉크·마스크를 초기화합니다. 사진별 장면 준비 사이에 화면 갱신 기회를 주고 동일 계획은 재사용합니다. 인코딩 시 임시 MessageChannel은 닫습니다. 연필 소리 합성과 획별 음량 처리는 루트 `app.js`의 초기 방식을 사용하며 오프라인 오디오 구간의 시간은 각 구간 시작 기준으로 보정합니다.

검증: `node renewal/test-browser.cjs --site`, `node renewal/test-browser.cjs --atelier`.
첫 명령은 반응형·이미지·메뉴를 확인합니다. 두 번째는 분석 지연, 기본값, 공통 제목·개별 편지, 반복 렌더링, 개별 PNG, 여러 사진 MP4, 원본 전체 가로 배치, 초기화를 확인합니다.

접속: 로컬 `/renewal/`, GitHub Pages `/pencil-sketch/renewal/`. 분석과 인코딩 라이브러리 일부는 인터넷에서 불러옵니다.

## 웅토끼 바로가기 설치

공개 페이지의 `바로가기 만들기` 버튼은 지원되는 Chrome·Edge에서 PWA 설치창을 열고, 아이폰·아이패드와 설치창을 제공하지 않는 브라우저에서는 홈 화면 추가 방법을 안내합니다. 설치 후에는 웅토끼 아이콘으로 팬 스튜디오를 바로 열 수 있습니다. 서비스 워커는 온라인 접속을 우선하며, 네트워크가 끊겼을 때만 캐시된 홈 화면을 표시합니다.

대표 아이콘 원본은 `icons/woong-rabbit-icon-master.png`입니다. 아이콘 크기를 다시 만들 때는 `python renewal/generate-site-icons.py`를 실행합니다. 공개 빌드에는 실제로 사용하는 32·180·192·512px 아이콘과 마스커블 아이콘만 포함합니다.

Cloudflare Pages의 파일당 제한에 맞춰 공개 파일은 모두 25MB 미만으로 유지합니다. `build-public-site.cjs`는 25MB 이상 파일을 발견하면 파일명과 크기를 표시하고 빌드를 중단합니다. 메인 웅토끼 영상은 1920×1080·30fps·36초를 유지한 고효율 H.264 파일입니다.

추가 UI 검증: `node renewal/test-browser.cjs --public-controls` — 공통 서명·글꼴, 편지 분리, 10단위 조절, 파노라마 배치, 초기값 복원을 검사합니다. ONNX의 `env.wasm.proxy`를 켜 무거운 모델 추론을 Web Worker로 분리했습니다([공식 안내](https://onnxruntime.ai/docs/tutorials/web/env-flags-and-session-options.html)).

## 아틀리에 연필화

기본 그림 모드는 `정밀 선화 (AI)`, 배경은 `햇살 화실 · 원목 이젤`입니다. 아틀리에 연필화도 선택할 수 있으며, `얼굴 정밀 확대 · 초상화` 구도를 제공합니다.

`studio-graphite.js`는 원본의 명암과 윤곽 방향을 샘플링해 가는 연필 해칭과 세부 윤곽을 그립니다. 기본은 백지에서 시작하며 형태 잡기 → 이목구비 → 머리카락·옷의 선 → 연필로 명암 칠하기 → 마지막 세부 묘사 순서입니다.

명암 획은 최대 6px 미만의 짧은 터치로 제한하며 손의 칠하기 범위도 약 10px로 줄였습니다. 명암은 작은 부위를 옅게 네 번 반복한 뒤 다음 부위로 이동하며 쌓습니다. 이동 중에는 칠하지 않습니다. 얼굴·머리카락·몸·손 분류는 작업 순서에 활용하지만 인위적인 얼굴 타원 경계에서 획을 자르지 않습니다. 실제 영상의 명암 차이를 기준으로 획을 멈추고, 얼굴 아래의 어두운 옷을 머리카락으로 분류하지 않도록 제한합니다. 자동 영역 추정에는 한계가 있습니다.

사진 구도의 `풍경 중심 · 배경까지 전체 그리기`는 얼굴 주변 마스크와 흐림 효과를 해제하여 원본 전체를 그립니다. `얼굴 중심 · 세로 확대`는 인물을 중심으로 배치합니다.

약 3만 개의 세밀한 획을 연필 끝 주변의 좁은 칠하기 동작으로 배치합니다. 종전의 17분 이상 자동 연장을 제거하고 최소 2분으로 제한했습니다. 희망 길이가 2분보다 길면 그대로 반영합니다. 서명·편지·입 움직임과 다음 사진의 시작 시간, 소리도 실제 길이에 맞춥니다. 이전보다 획의 방향과 굵기, 밀도가 달라져 완성 그림의 연필 질감도 달라집니다.

120초를 넘는 영상은 지원 브라우저에서 OPFS 임시 디스크 파일에 인코딩합니다. [사용 중인 MP4 muxer의 파일 스트림 대상](https://app.unpkg.com/mp4-muxer%405.2.1/files/README.md)을 이용하며 MP4는 파일 끝에 재생 시간과 탐색 정보를 기록하는 일반 구조를 사용합니다. 다운로드 후 임시 파일을 정리하고, 중단된 임시 파일은 다음 저장 시 하루가 지난 것만 정리합니다. 전체 영상을 메모리에 쌓는 부담을 줄이지만 긴 영상은 저장 시간과 디스크 공간도 더 필요합니다.

밝은 원본과 작은 얼굴은 제공할 수 있는 디테일 자체가 제한됩니다. 홈페이지의 생성 초상화와 모든 사진에서 동일한 미술적 결과를 보장하지는 않습니다.

햇살 원목 화실을 기본으로 유지하고, 초록 정원 화실·저녁 서재 화실을 선택할 수 있습니다. 세 종류 모두 가로·세로 전용 배경을 사용하며 실제 빈 종이 좌표에 그림을 합성합니다. 새 배경은 내장 이미지 생성 도구로 제작했고 프롬프트는 `assets/atelier/THEMES-PROMPTS.md`에 보관합니다. 투명한 새 손 자산을 연필 끝에 정렬하며 피부를 변형하지 않습니다. 자산 및 생성 프롬프트는 `assets/atelier/`에 있습니다. 이전 손 코드는 `hand-original.js`에 보관했습니다.

`node renewal/test-browser.cjs --graphite --video`는 실제 PNG·MP4 결과를 `.test-output/graphite/`에 저장합니다. `--art-review`는 이 결과의 비교 페이지를 캡처합니다. 테스트 출력과 입력 인물 사진은 배포 파일에 포함하지 않습니다.

`node renewal/test-browser.cjs --sweeps --full` (`--process`도 동일)은 미세 획의 4회 누적·누락, 풍경 배경 포함, 획 방향 다양성, 연필 끝과의 거리, 2분 타임라인, 편지·서명 시간, 서로 다른 길이의 사진 전환을 검사합니다. 명암 구간 18초와 전체 2분 MP4, 세 화실의 가로·세로 결과를 `.test-output/layers/`에 저장합니다. `--atelier`는 짧은 선화 모드로 공통 다중 사진·편지·PNG·MP4 기능을 검증합니다.
