# 영웅시대 미담 영상 자산

2026-10-02 내장 이미지 생성 도구로 제작한 프로젝트 전용 자산입니다.

## 배경

- `hospital.webp`: 한국의 밝고 따뜻한 소아 지원센터, 인물과 글자 없이 중앙 동선 확보
- `rice.webp`: 백미 나눔을 준비한 복지관 입구, 쌀 포대와 손수레를 양옆에 배치
- `pantry.webp`: 쪽방촌 주민을 위한 식료품 온기창고, 포장 작업 공간 확보
- `wildfire.webp`: 산불이 지나간 한국 산촌의 복구 현장, 구호 물품과 회복 중인 숲
- `flood.webp`: 집중호우 뒤의 한국 마을 복구 현장, 구호 상자와 청소 도구
- `finale.webp`: 전국의 파란 나눔 불빛이 하나로 연결되는 야간 항공 장면

## 캐릭터

- `volunteer-actions.png`: 한국 60대 여성 봉사자 6동작 투명 스프라이트 시트
  1. 쌀 포대 운반
  2. 손수레 밀기
  3. 구호 상자 포장
  4. 상자 전달
  5. 의료용 주머니 들기
  6. 손을 가슴에 얹은 인사

모든 자산은 로고, 워터마크, 읽을 수 있는 문구 없이 생성했습니다.
