# 군고구마 3D 샘플 자산

- `hero-vendor.png`: 겨울 군고구마 장수 모습의 임영웅 캐릭터
- `woong-rabbit-potato.png`: 군고구마를 안고 몰래 이동하는 웅토끼

두 자산은 사용자가 제공한 인물 사진과 기존 승인된 웅토끼 디자인을 참조하여 내장 ImageGen으로 생성했습니다. 투명 PNG를 Three.js 공간 속 입체 카드로 배치하고 3D 조명, 그림자, 카메라, 화로, 눈발, 연기와 결합합니다.

- `winter-alley.png`: 고급 3D 애니메이션풍 눈 내리는 한국 골목 환경판

- `sweet-potato-cart.png`: 고급 3D 애니메이션풍 군고구마 수레
