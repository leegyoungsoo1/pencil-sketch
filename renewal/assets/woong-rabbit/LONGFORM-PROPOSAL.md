대안 문구: **팬들이 감동한 진짜 이유**. 추천안보다 포괄적이므로, 실제 완성 영상의 첫 30초와 가장 잘 맞는 쪽을 선택한다.

제작 순서: 기획 승인 → 장면·음향 샘플 → 클립 제작 → 해설 길이 조정 → 합본 → 제목 확정 → 썸네일 이미지 2안 → 최종 선택. 지금은 썸네일 생성하지 않는다.

## 보관과 관리

- 보관 상한을 최근 3개에서 최근 20개로 변경. 30초 클립 20개는 단순 합계 약 10분이며 연결·출처 화면에 따라 최종 길이는 달라진다.
- 기존 사진 이야기 보관함의 등록 스크립트와 화면 표시 제한은 이번 작업에서 20개로 변경한다.
- 웅토끼는 현재 단독 에피소드 페이지이며, 클립 20개 보관·정렬·합본 UI는 아직 없다. 승인 후 제작할 때 별도의 작품 ID와 clip-01~clip-20 순서로 묶고 등록한다.
- 등록순 보관 순서와 영상 내 재생 순서는 별개로 관리한다. 합본에 사용 중인 클립은 자동 정리 대상에서 보호하는 구조가 필요하다.
- 캐릭터·배경·효과음은 공용 자산으로 분리. 클립이 정리되어도 공용 자산은 삭제하지 않는다.
- 보관 한도 변경을 적용하면서 현재 파일을 삭제하지 않는다. 이번 검증은 임시 테스트 폴더에서만 수행한다.
