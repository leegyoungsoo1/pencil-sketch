# 이야기 영상 공통 제작 기준

2026-10-03부터 제작하는 모든 롱폼·쇼츠에 적용한다.

## 나레이션

- 전체 나레이션은 장면별 파일로 나누지 않고 한 파일로 제공한다.
- 실제 TTS 길이가 영상보다 최소 4초 짧도록 작성한다.
- 한국어 기준 초당 약 3.5~4자를 목표로 하고, 쉼표와 문장 사이의 호흡 시간도 포함한다.
- 사실 설명을 반복하지 않고 쉬운 문장으로 쓴다.
- 롱폼과 쇼츠 모두 마지막 문장은 `오늘도 건강하고 행복하세요. 건행~`으로 통일한다.

## 캐릭터 이미지

- 스프라이트 시트를 영상에서 직접 균등 분할해 사용하지 않는다.
- 각 자세를 독립된 투명 PNG로 분리한 뒤 사용한다.
- 머리·머리카락·손가락·발·의상·소품 주위에 최소 12%의 투명 여백을 둔다.
- 알파 영역이 이미지 네 변에 닿거나, 이웃 자세의 조각이 들어온 이미지는 사용하지 않는다.
- 걷기 방향과 이동 방향을 일치시키고, 자세 전환 시 두 전신 이미지를 길게 겹치지 않는다.

## 최종 검사

- 모든 장면의 시작·중간·끝 프레임을 추출해 사람 눈으로 검사한다.
- 머리 잘림, 손·발 잘림, 다른 자세의 얼굴·소품 유입, 잔상, 순간이동을 확인한다.
- 가로 롱폼과 세로 쇼츠를 각각 검사한다.
- 썸네일에 사용하는 인물도 별도로 검사한다.
- MP4 길이·해상도·영상 트랙·오디오 트랙과 모바일 화면 폭을 자동 검증한다.
