# 팬들이 이번엔 꿈을 키웠습니다

내장 ImageGen으로 제작한 프로젝트 전용 이미지입니다.

- `backgrounds/practice.webp`: 해 질 무렵 대학 보컬 연습실
- `backgrounds/planning.webp`: 팬 운영진이 행사를 준비하는 밝은 회의 공간
- `backgrounds/backstage.webp`: 공연 직전 긴장감이 감도는 무대 뒤
- `backgrounds/stage.webp`: 파란색과 금색 조명의 보컬 경연 본무대
- `backgrounds/award.webp`: 꽃과 트로피가 놓인 시상식 무대
- `backgrounds/finale.webp`: 파란 응원 불빛이 펼쳐진 피날레 공연장
- `student-actions.png`: 연습·긴장·입장·노래·인사·수상 학생 6동작
- `fan-actions.png`: 기획·무대 준비·격려·박수·눈물·응원봉 팬 운영진 6동작

모든 배경은 인물을 합성할 공간을 남긴 16:9 실사형 영상 플레이트로 요청했습니다. 캐릭터 시트는 동일 인물과 의상을 유지하고 머리·손·발이 잘리지 않는 3×2 투명 시트로 요청했습니다.
