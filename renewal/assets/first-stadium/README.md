# 일흔 살 엄마의 첫 스타디움

내장 ImageGen으로 제작한 영상 전용 이미지입니다.

- `backgrounds/home-morning.webp`: 콘서트를 준비하는 아침 거실
- `backgrounds/subway.webp`: 공연장으로 향하는 지하철 승강장
- `backgrounds/stadium-plaza.webp`: 파란 응원봉이 모인 스타디움 광장
- `backgrounds/concourse.webp`: 입장 동선을 표현하는 내부 공간
- `backgrounds/stadium-inside.webp`: 파란빛으로 가득한 공연장
- `backgrounds/home-night.webp`: 공연을 마치고 돌아온 밤의 거실
- `mother-actions.png`: 준비·걷기·길 찾기·입장·응원·눈물 12동작
- `friend-actions.png`: 인사·안내·걷기·표 확인·웃음·응원·손잡기 8동작
