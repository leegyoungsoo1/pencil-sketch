# 취재·이미지 기록

확인: 2026-09-29 (한국 시간).

- 공식 YouTube 페이지에서 제목과 공식 아티스트 채널 확인. 자막 내보내기는 자막 없음으로 실패. 원본 전체를 시청·대조했다고 주장하지 않는다.
- 여행 세부 사건은 트롯뉴스 2026-09-26 보도를 짧게 요약했다. 친구들과 축구 여행, 홍수 경보와 요리, 선물만 사용. 기사 전체 서사나 문장 복제는 하지 않았다.
- 음악적 목표는 파이낸셜뉴스 2026-09-25 보도를 요약했다. 직접 인용은 사용하지 않았다.
- 보도마다 게시일 표기가 달라 영상 업로드 날짜, 정확한 여행 날짜, 경기 결과는 대본에서 제외했다. 현재 뉴욕에 있다고 표현하지 않는다.
- 감상·시청자 질문은 창작 해설이며 해당 인물의 실제 속마음·발언이라고 제시하지 않는다.
- city.png / table.png: 내장 이미지 생성 도구의 개념 삽화. 실제 여행 장소·숙소·식탁 사진이 아니다. 생성 모델 이름은 지정하거나 확인하지 않았다.
- portrait.png: 사용자가 이전에 제공한 임영웅6.png를 변경 없이 복사. 여행 현장 사진이 아님. 사진 이용 허락·라이선스가 확인되었다고 주장하지 않는다.
